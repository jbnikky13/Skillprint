# Skillprint

> Your professional fingerprint, matched against the world's opportunities.

Skillprint is a career fingerprinting engine inspired by the core idea behind systems like Shazam: represent complex information as a compact, comparable fingerprint, then use fast matching to discover the strongest matches.

Instead of treating a CV as a document and a job description as a pile of keywords, Skillprint converts candidate evidence and opportunities into structured career fingerprints.

## What makes Skillprint different

- Career fingerprinting rather than simple keyword matching
- Evidence-aware matching using CVs, portfolio projects and real work
- Multiple CVs with automatic CV selection per opportunity
- Global-first discovery with remote eligibility as a first-class signal
- AI-assisted deep matching after fast candidate retrieval
- Truth-first applications that never invent qualifications
- Application automation with configurable approval controls

## MVP

1. Normalize candidate and job information.
2. Generate deterministic career fingerprints.
3. Calculate similarity between candidate and job fingerprints.
4. Explain matched and missing signals.
5. Select the strongest CV profile.
6. Expose the engine through a small TypeScript API.

The job-ingestion, browser automation, application generation and dashboard layers come after the fingerprint engine proves itself.
